This project demonstrates the knowledge of Python code fundamentals to successfully create a small shopping application.
- shop_class.py
  - file defines classes, objects, attributes, and methods shop_gui.py will use.
  - reads and retrieves information from CSV file
  
- shop_gui.py file
  - provides the user interface using Python's built-in library for GUI, Tkinter.
  - calls methods from the class file and displays calculations.
  
- Top50ShopifyApps.csv
  - stores the application's data
